# Data dictionary

Published tables in schema `main_marts`. Generated by `make docs` (`pipeline/build_data_dictionary.py`) from the dbt .yml files and the DuckDB warehouse; do not edit by hand.

## fct_po_lines

One row per PO line (charter "Measurement grain") with OTIF outcome flags evaluated as of run_date. Filter is_eligible for scorecard math.

Table-level tests:

- expression_is_true: `(receipt_count = 0) = (first_receipt_date is null)`
- expression_is_true: `isodow(attribution_week_start) = 1 and requested_delivery_date between attribution_week_start and attribution_week_start + 6`
- expression_is_true: `cases_received_in_window <= cases_received_total`

|---|---|---|---|
| `po_line_id` | VARCHAR | PO line key. | unique; not_null |
| `po_number` | VARCHAR | Parent PO. | not_null |
| `supplier_id` | VARCHAR | Supplier on the PO. | not_null; relationships to stg_suppliers.supplier_id |
| `dc_id` | VARCHAR | Receiving DC. | not_null; relationships to stg_distribution_centers.dc_id |
| `sku` | VARCHAR | SKU ordered. | not_null |
| `line_status` | VARCHAR | active, cancelled_by_northfield, or cancelled_by_supplier. | accepted_values: active, cancelled_by_northfield, cancelled_by_supplier |
| `requested_delivery_date` | DATE | Requested delivery date (DC local date). | not_null |
| `attribution_week_start` | DATE | Monday of the ISO week of requested_delivery_date. | not_null |
| `attribution_iso_week` | VARCHAR | ISO year-week label, e.g. 2026-W43. |  |
| `ordered_cases` | INTEGER | Cases ordered. |  |

## fct_receipts

One row per dock receipt recorded on or before run_date, including receipts that can't be scored (see receipt_issue). Incremental (delete+insert on receipt_id) with a receipt_lookback_days window on recorded_date; run with --full-refresh after changing run_date backwards or reloading old partitions.

| Column | Type | Description | Tests |
|---|---|---|---|
| `receipt_id` | VARCHAR | Receipt key. | unique; not_null |
| `po_line_id` | VARCHAR | PO line received against; may not exist for orphan receipts. | not_null |
| `po_number` | VARCHAR | PO received against, as recorded at the dock. |  |
| `supplier_id` | VARCHAR | Supplier of the matched PO; null for orphans. |  |
| `dc_id` | VARCHAR | Receiving DC. | not_null; relationships to stg_distribution_centers.dc_id |
| `sku` | VARCHAR | SKU received (normalized). | not_null |
| `requested_delivery_date` | DATE | Requested delivery date of the matched PO; null for orphans. |  |
| `received_at` | TIMESTAMP | Receipt timestamp, DC local time; null when missing in the source. |  |
| `received_date` | DATE | DC local date of received_at. |  |
| `recorded_date` | DATE | Date the receipt was recorded (raw partition); drives the incremental window. | not_null |
| `days_from_requested` | BIGINT | received_date minus requested_delivery_date (negative = early). |  |
| `received_cases` | INTEGER | Cases received as recorded (zero/negative values are flagged, not fixed). | not_null |
| `rejected_cases` | INTEGER | Cases refused at the dock. | not_null |
| `receipt_issue` | VARCHAR | Null when scoreable; else orphan_po_line, missing_received_at, or nonpositive_cases. | accepted_values: orphan_po_line, missing_received_at, nonpositive_cases |
| `is_scoreable` | BOOLEAN | True when the receipt counts toward OTIF. | not_null |
| `is_in_on_time_window` | BOOLEAN | Scoreable and received within the charter's on-time window. | not_null |

## mart_supplier_otif_weekly

Weekly OTIF scorecard: one row per supplier per attribution week (both DCs combined), for weeks starting on or before run_date. Used in the Monday vendor review. Rows with is_provisional = true can still change.

Table-level tests:

- unique_combination_of_columns: supplier_id, attribution_week_start
- expression_is_true: `(eligible_lines = 0) = (otif_pct is null)`
- expression_is_true: `otif_lines <= on_time_lines and otif_lines <= in_full_lines and on_time_lines <= eligible_lines and in_full_lines <= eligible_lines`

| Column | Type | Description | Tests |
|---|---|---|---|
| `supplier_id` | VARCHAR | Supplier key. | not_null; relationships to stg_suppliers.supplier_id |
| `supplier_name` | VARCHAR | Supplier name. | not_null |
| `supplier_category` | VARCHAR | Supplier merchandise category. |  |
| `attribution_week_start` | DATE | Monday of the ISO attribution week. | not_null |
| `attribution_week_end` | DATE | Sunday of the ISO attribution week. |  |
| `attribution_iso_week` | VARCHAR | ISO year-week label, e.g. 2026-W43. |  |
| `is_provisional` | BOOLEAN | True until 7 days after the week ends (charter "Provisional"). | not_null |
| `as_of_date` | DATE | var('run_date') the scorecard was computed at. |  |
| `total_lines` | BIGINT | All PO lines attributed to the week, including Northfield-cancelled. |  |
| `eligible_lines` | BIGINT | Lines due and not cancelled by Northfield (OTIF % denominator). |  |
| `otif_lines` | BIGINT | Eligible lines that were on time and in full (OTIF % numerator). |  |
| `on_time_lines` | BIGINT | Eligible lines that were on time. |  |
| `in_full_lines` | BIGINT | Eligible lines that were in full. |  |
| `missed_lines` | BIGINT | Eligible lines with no receipt by requested date + 7 days. |  |
| `supplier_cancelled_lines` | BIGINT | Eligible lines cancelled by the supplier (counted as failures). |  |
| `northfield_cancelled_lines` | BIGINT | Lines cancelled by Northfield (excluded from eligibility). |  |
| `over_shipment_lines` | BIGINT | Eligible lines received above 105% of ordered. |  |
| `eligible_cases_ordered` | BIGINT | Cases ordered on eligible lines (case fill rate denominator). |  |
| `eligible_cases_received` | BIGINT | Scoreable cases received on eligible lines (case fill rate numerator). |  |
| `otif_pct` | DOUBLE | 100 x otif_lines / eligible_lines; NULL when eligible_lines = 0. | accepted_range: 0..100 |
| `on_time_pct` | DOUBLE | 100 x on_time_lines / eligible_lines; NULL when eligible_lines = 0. | accepted_range: 0..100 |
| `in_full_pct` | DOUBLE | 100 x in_full_lines / eligible_lines; NULL when eligible_lines = 0. | accepted_range: 0..100 |
| `case_fill_rate_pct` | DOUBLE | 100 x eligible_cases_received / eligible_cases_ordered (can exceed 100 with over-shipments); NULL when eligible_lines = 0. | accepted_range: 0.. |
